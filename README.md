# agyat4.github.io

Personal academic website of **Prasiddha Siwakoti**, Ph.D. student in Electrical Engineering at West Virginia University.

Live at **https://agyat4.github.io**

Built with [Hugo](https://gohugo.io) (v0.136.5 extended) and the [Hugo Blox](https://hugoblox.com) `blox-tailwind` theme, and deployed to GitHub Pages by `.github/workflows/publish.yaml` on every push to `main`.

## Editing

- Profile, education and bio: `content/authors/admin/_index.md`
- Publications: `content/publication/<slug>/index.md` (+ `featured.png` thumbnail)
- Projects: `content/project/<slug>/index.md`
- News: `content/post/<slug>/index.md`
- Skills & Experience page: `data/skills.yaml`
- CV download: `static/uploads/resume.pdf`

## Local preview

```bash
hugo server
```
